# E-Waste-Management-System
A mini project developed for the Computer Workshop (CWS) Lab at college. This project is a frontend prototype of an E-Waste Management System, designed using Figma and implemented with HTML, CSS, and Bootstrap. The project demonstrates a user-friendly interface for promoting responsible e-waste disposal.
